# aws-secure-static-site

🚧 In Progress

Hosting a secure static website on AWS using S3, CloudFront, and HTTPS via ACM. Configured with IAM least-privilege access and S3 logging.

## AWS Services Used
- Amazon S3 — static file hosting
- CloudFront — content delivery and HTTPS
- ACM — SSL certificate
- IAM — least-privilege access policy
